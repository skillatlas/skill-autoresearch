Generate a single-page website as `index.html` that showcases the frontend-design skill.

## Requirements

Build a portfolio-style landing page for a fictional creative studio called "Atelier Nox". The page must include:

1. **Hero section** — studio name, a one-line tagline, and a "View Work" CTA
2. **Work showcase** — at least 4 project cards with placeholder titles, short descriptions, and category labels (e.g. "Branding", "Web", "Motion", "Editorial")
3. **About section** — a short paragraph about the studio's philosophy
4. **Contact section** — an email address and minimal social links (use `#` hrefs)
5. **Footer** — copyright line

## Technical constraints

- Single self-contained `index.html` file (inline CSS and JS — no external dependencies except Google Fonts or similar CDN fonts)
- Must be responsive down to 320px viewport width
- Must respect `prefers-reduced-motion`
- Semantic HTML (`header`, `main`, `section`, `nav`, `footer`, `button` — no div soup)
- All interactive elements must be keyboard-accessible with visible focus states

## Creative direction

Apply the frontend-design skill fully. Choose a bold, distinctive aesthetic — not a safe corporate template. The page should have:

- A clear, committed visual identity (typography, color, layout, atmosphere)
- At least one signature element that makes the design memorable
- Intentional motion: a page-load entrance sequence and meaningful hover/interaction states
- Spatial depth: backgrounds, textures, shadows, or layering — never flat white

Avoid generic AI aesthetics: no Inter/Roboto, no purple-to-blue gradients on white, no hero-cards-testimonials-CTA template layouts.

The result should look like it was designed by a human with a strong point of view.
